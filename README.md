# Recommendation Engine for Personalized Learning

**Client:** EdTech Platform  
**Role:** ML Engineer  
**Stack:** PyTorch, Redis, FastAPI, AWS EC2, PostgreSQL, Grafana

## Challenge
Users were dropping off after 3 sessions because content felt generic and irrelevant.

## Solution
Built a hybrid collaborative + content-based filtering model using PyTorch, served via a Redis-cached FastAPI endpoint, and A/B tested against their old rule-based system.

## Result
- Increased average session time by **35%**
- Reduced 30-day churn from **40% to 27%**

## Key Skills
- Recommendation Systems (Collaborative + Content-Based)
- Deep Learning (PyTorch)
- Caching (Redis)
- A/B Testing
